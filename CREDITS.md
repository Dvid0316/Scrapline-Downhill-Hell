# Credits

## Textures: Poly Haven (CC0)

All of these come from [Poly Haven](https://polyhaven.com) and are released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain,
no attribution required; credited here anyway). The game doesn't use them as
photos. Their luminance is remapped onto a hand-picked stylized palette in the
shaders (`shaders/stylized_*.gdshader`).

| Texture | Used for |
|---|---|
| [sparse_grass](https://polyhaven.com/a/sparse_grass) | terrain grass |
| [dry_ground_rocks](https://polyhaven.com/a/dry_ground_rocks) | terrain dirt shoulder |
| [rock_face](https://polyhaven.com/a/rock_face) | mountain cliffs, boulders |
| [gravel_floor](https://polyhaven.com/a/gravel_floor) | track-bed gravel |
| [rusty_painted_metal](https://polyhaven.com/a/rusty_painted_metal) | rust streak mask on painted metal |
| [rust_coarse_01](https://polyhaven.com/a/rust_coarse_01) | metal grunge and detail normals |

## Everything else

Original work made for this project: procedural geometry (terrain, rocks,
trees, grass, smoke puffs), all shaders, all scenes, and all sounds
(synthesized by `tools/gen_sfx.py`).
